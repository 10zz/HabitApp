# Habit Tracker (Трекер привычек)
Мобильное приложение для отслеживания ежедневных привычек, разработанное на React Native. Позволяет создавать привычки, назначать им эмодзи и цвета, отмечать выполнение и просматривать статистику
# Технологии
В проекте использованы следующие библиотеки и инструменты:
- React Native (CLI) — основа мобильного приложения.
- TypeScript — для типизации кода.
- React Navigation (v7) — навигация:
    - @react-navigation/native
    - @react-navigation/native-stack (корневой стек)
    - @react-navigation/bottom-tabs (нижняя панель)
- MMKV (react-native-mmkv) — быстрое локальное хранилище.
- react-native-emoji-chooser — выбор эмодзи для иконки привычки.
- react-native-safe-area-context — отображение с учетом системных панелей.
# Требования к ПО:
- Node.js (версия 18+)
- npm или yarn
- Android Studio (Android) и JDK 17 (Android)
- Xcode (iOS)
# Установка и запуск
1. Клонирование репозитория и установка зависимостей
```
git clone https://github.com/10zz/Demo2
cd https://github.com/10zz/Demo2

# Установка npm-пакетов
npm install
# или
yarn install
```
2. Запуск на устройстве или эмуляторе

Android:
```
npm run android
# или
yarn android
```
iOS:
```
npm run ios
# или
yarn ios
```
